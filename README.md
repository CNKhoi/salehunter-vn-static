- Không cần Docker.
- `config.js` đã được cấu hình để đọc dữ liệu từ repo công khai `CNKhoi/salehunter-vn-static`.

- “Mã có thể sao chép” **không đồng nghĩa** mã còn lượt hoặc áp dụng thành công tại thanh toán.
